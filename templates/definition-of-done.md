# Definition of Done (DoD) – Oyun Geliştirme

Bir User Story’nin veya feature’ın **gerçekten bitti** sayılması için aşağıdaki kriterlerin hepsinin sağlanması gerekir.

## Genel Definition of Done

- [ ] Kod yazıldı ve review edildi
- [ ] Unit testler yazıldı ve geçti
- [ ] QA tarafından test edildi
- [ ] Bulunan kritik ve major bug’lar düzeltildi
- [ ] Dokümantasyon güncellendi (gerekirse)
- [ ] Product Owner / Business Analyst onayladı
- [ ] Feature canlı ortamda (veya staging’de) sorunsuz çalışıyor

## Oyun Sektörüne Özel Kriterler

- [ ] Oynanış dengesi test edildi
- [ ] Performans sorunu yok (FPS, yükleme süresi)
- [ ] Farklı cihazlarda test edildi (mobil ise)
- [ ] UI/UX tutarlı görünüyor
- [ ] Lokalizasyon (çeviri) tamamlandıysa kontrol edildi

## Live Ops / Event İçin Ek Kriterler

- [ ] Event başlangıç ve bitiş tarihleri doğru
- [ ] Ödüller doğru şekilde veriliyor
- [ ] Analytics event’leri eklendi
- [ ] Oyuncu feedback’i için hazırlık yapıldı

---

**Not:**  
Definition of Done, takımın ortak anlaşmasıdır. Her sprint sonunda gerekirse güncellenebilir.
